# The Systems Behind Me

Personal portfolio for Saw Luke Loo (Luke) Wah, built with Astro and TypeScript as a static site.

## Local development

```sh
pnpm install
pnpm dev
```

Run `pnpm check` for Astro and TypeScript diagnostics and `pnpm build` to create the static site in `dist/`.
